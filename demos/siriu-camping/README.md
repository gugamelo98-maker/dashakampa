# Siriu Camping — demonstração

Versão de demonstração do painel para apresentar a um camping que recebe só barracas e motorhomes.

- Não usa o servidor real: `demo-api.js` simula todas as respostas no próprio navegador.
- Dados fictícios, gerados a partir da data de hoje. Tudo volta ao início ao recarregar a página.
- `index.html` é gerado a partir do painel principal (`/index.html`) com `python3 gerar.py <pasta>`
  (o script grava em `<pasta>/site/index.html`).
